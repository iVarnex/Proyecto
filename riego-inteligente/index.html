    Atajos de teclado

    Acerca del proyecto

    Tablero web de monitoreo y control para un sistema de riego inteligente, desarrollado como parte de un proyecto STEM interdisciplinario que integra robótica (sensores y actuadores simulados en Wokwi), comunicación inalámbrica WiFi y desarrollo web con HTML, CSS y JavaScript.

    ODS 6 · Agua limpia y saneamiento ODS 12 · Producción y consumo responsables

    Cómo usar el tablero

    1. Observa los sensores. Las cuatro tarjetas muestran la lectura en vivo. El color y el texto bajo cada número indican si el valor está en rango.
    2. Define el umbral. Mueve el deslizador para fijar la humedad mínima tolerable del cultivo. La línea punteada del gráfico se mueve contigo.
    3. Elige el modo. En Automático la bomba se activa sola al cruzar el umbral hacia abajo. En Manual el botón de la bomba se habilita para que la controles tú.
    4. Prueba un escenario. Los escenarios de la barra superior fuerzan condiciones extremas (calor, lluvia, fuga, falla de sensor) para demostrar cómo responde el sistema.
    5. Consulta el asistente. Analiza la telemetría con reglas explícitas y propone acciones correctivas.
    6. Exporta la evidencia. Bitácora, telemetría o el proyecto completo, para anexar al informe APA.

    Sobre el asistente de diagnóstico

    El asistente no es un modelo de lenguaje ni aprendizaje automático. Es un sistema experto determinista: cada recomendación nace de una regla escrita explícitamente en js/assistant.js. Puedes leer la condición, predecir la salida y comprobarla — que es justamente el objetivo pedagógico del pensamiento computacional.
